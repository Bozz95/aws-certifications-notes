# Amplify

## Intro

Managed service by AWS where you can more or less what Google Firebase can.

It is a service for developer who wants the basic things for their standard app without configuring too much or having to manage anything.

It integrates directly to github, CodeCommit, Bitbucket, Gitlab or direct upload via zip or S3.

It offers services like:

- authentication
- Storage
- API (REST or GraphQL)
- CI/CD
- PubSub
- analytics
- AI/ML predictions
- Domain management and publication

Supports multiple languages and it ideal for webapps or mobile apps.

It supports branch or environemtn deploy by default, meaning it can tracks each one of the branches in the repository and deploy to a custom domain according to the branch name.
